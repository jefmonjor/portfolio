# Portfolio Content Style Guide

## Voice

- Direct, specific, and evidence-led.
- Avoid generic claims such as "passionate developer" unless backed by concrete
  examples.
- Prefer active verbs and measurable outcomes.

## Project Case Study Shape

```text
Title:
One-line summary:
Problem:
Role:
Constraints:
Technical decisions:
Stack:
Outcome:
Links:
```

## CV Content Shape

```text
Role:
Organization:
Dates:
Location or remote:
Summary:
Highlights:
Technologies:
```

## Writing Rules

- Keep card copy short.
- Put deeper explanation on detail pages or expandable sections.
- Use consistent date formats.
- Avoid unsupported metrics. If a number is approximate, label it clearly.
- Keep private client details out unless approved for public use.
