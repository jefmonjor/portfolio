# Portfolio Content

## Required Context

Read:

- `.ai/context/product.md`
- `.ai/styles/content.md`

## Content Rules

- Prefer facts, decisions, outcomes, and artifacts over generic claims.
- Keep public content safe: do not expose private client data, secrets, internal
  URLs, or confidential metrics.
- Use consistent names for technologies and organizations.
- Keep dates consistent.
- Model repeated content as typed data when it will be reused.

## Project Entry Checklist

- Title.
- One-line summary.
- Problem or context.
- Enrique's role.
- Technical decisions.
- Stack.
- Outcome or learning.
- Public links when available.

## CV Entry Checklist

- Role.
- Organization.
- Dates.
- Location or remote status.
- Summary.
- Highlights.
- Technologies.
